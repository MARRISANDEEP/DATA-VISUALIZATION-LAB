# Experiment No. 2: Basic Visualization in Python

## Aim
To implement basic graphical representations in Python using Matplotlib and understand how different chart types present and communicate data.

## Description
Data visualization transforms numerical information into graphical forms that are easier to interpret. Python supports visualization through libraries that provide functions for generating charts and plots. Among these libraries, Matplotlib is commonly used because it offers flexible tools for creating graphs and modifying their appearance.

Different visualizations serve different analytical purposes. Line charts help track changes over time or across ordered values. Bar charts compare separate groups, while pie charts illustrate how categories contribute to a total. Scatter plots reveal possible relationships between numerical variables, and histograms summarize the distribution of numerical data.

This experiment demonstrates five fundamental chart types using sample datasets. Titles and axis labels are included where appropriate to make the visualizations understandable and informative.

## Applications
- Presenting data in a clear graphical format.
- Comparing values across categories.
- Observing changes and trends in a dataset.
- Examining relationships between numerical measurements.
- Understanding the distribution of data values.
- Communicating findings through visual reports.

## Algorithm
1. Begin the program and import the Matplotlib plotting module.
2. Define sample data suitable for each type of chart.
3. Choose the appropriate plotting function for the data.
4. Generate the required visualization.
5. Add a meaningful title and axis labels where applicable.
6. Display each chart using the plotting interface.
7. Observe the graphs and identify the information they communicate.

## Libraries and Functions Used

| Library / Function | Purpose |
|---|---|
| `matplotlib.pyplot` | Provides plotting and chart customization features. |
| `plot()` | Creates a line chart. |
| `bar()` | Produces a bar chart for category comparison. |
| `pie()` | Displays the proportions of categories in a circular chart. |
| `scatter()` | Represents pairs of numerical values as points. |
| `hist()` | Displays the frequency distribution of numerical observations. |
| `title()` | Adds a heading to the chart. |
| `xlabel()` and `ylabel()` | Describe the horizontal and vertical axes. |
| `show()` | Displays the generated visualization. |

## Result
The five basic visualization types—line chart, bar chart, pie chart, scatter plot, and histogram—were implemented using Python's Matplotlib library. The experiment demonstrates how different graphical techniques can be selected to compare categories, examine trends, study relationships, and understand data distributions.
